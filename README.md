# Descripción del Trabajo:
Este trabajo práctico tiene como objetivo aplicar los fundamentos de React y la manipulación de arrays en JavaScript. Para eso realizamos actividades como:
* Desarrollar una aplicación de lista de tareas en React, que permite agregar, listar, eliminar y marcar las tareas completas. Se utilizaron componentes funcionales, props, y el hook "useState".
* Además, se creó un script en JavaScript para gestionar un array de objetos, representando productos. Se implementaron funciones para mostrar, filtrar, mapear, ordenar, agregar y eliminar elementos del array.
